연결

이 PC에서 toss-connector가 실행 중이어야 합니다. 토큰은 터미널에서 toss-connector console token으로 확인할 수 있습니다.

덱

새 덱 페어링
먼저 덱에서: 설정 → Paired devices → PAIR NEW DEVICE

명령

덱의 명령 위젯(버튼, 스위치, 노브)에서 사용할 명령을 관리합니다. 덱에서는 여기에 등록된 항목만 선택할 수 있으며 실제 실행 커맨드는 덱으로 전달되지 않습니다. 덱에서 실행하려면 해당 덱에 명령 실행 권한을 허용해야 합니다.
